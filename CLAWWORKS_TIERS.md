# ClawWorks Tier Definitions

Created: 2026-05-21

Use this as the source of truth when onboarding ClawWorks clients or configuring client-specific agents/workflows.

## Workflow Audit

Price: `$250 setup`, no monthly upkeep.

Purpose: Identify the best first workflow to systemize.

Scope:

- 60-minute workflow review
- Admin bottleneck map
- Priority automation shortlist
- No dedicated client agent unless the audit converts into a build

## Starter System

Price: `$750 setup`, then `$300/mo upkeep after month one`.

Purpose: Prove one focused workflow works before expanding.

Scope:

- One core admin workflow
- Setup, testing, and documentation
- First month support included
- Basic monitoring, fixes, and small rule changes
- Clear upgrade path into Starter Plus or Operations System

Agent/client setup expectation:

- Create one client-specific agent/session focused on the chosen workflow.
- Keep scope narrow: one workflow, one primary owner, clear trigger, clear output.
- Avoid adding extra workflows unless the client upgrades.

## Starter Plus

Price: `$1,250 setup`, then `$500/mo upkeep after month one`.

Purpose: One high-value workflow with active monthly improvement.

Scope:

- One high-value workflow
- Monthly optimization review
- Light reporting on activity and bottlenecks
- One small enhancement per month
- More active support than Starter System

Agent/client setup expectation:

- Create one client-specific agent/session for the workflow plus lightweight reporting.
- Track monthly improvement backlog.
- Allow one small enhancement per month without treating it as a full Operations System.

## Operations System

Price: `From $3,000 setup`, then `from $1,000/mo upkeep after month one`.

Purpose: Expand a proven workflow into a multi-workflow operating system.

Scope:

- Multiple connected workflows
- Intake, reminders, routing, reporting, and task handoffs
- Owner visibility and documentation
- Ongoing monitoring, fixes, and improvements
- Higher upkeep for heavier volume, complex integrations, high-touch support, or larger workload

Agent/client setup expectation:

- Create a dedicated client-specific agent setup with multiple workflow responsibilities.
- Define each workflow explicitly: trigger, inputs, actions, approval points, outputs, escalation path.
- Include recurring reporting and an improvement backlog.
- If workload is heavy or support demand is high, quote upkeep above `$1,000/mo`.

## Positioning Rule

Starter tiers should be limited by breadth, not quality. A Starter System should feel complete and reliable for one narrow problem. The upgrade path exists because the client sees value and wants additional workflows, deeper reporting, more integrations, or heavier support.
